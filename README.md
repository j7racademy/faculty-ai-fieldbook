# J7R Faculty AI Fieldbook

A static participant companion for the J7R Academy Adopt, Adapt, Advance webinar, 22 October 2026, 7:00–9:00 PM IST.

The five guided workflows support junior Indian clinical faculty with Phase II MBBS teaching, interruption-aware planning, hospital administration, research preparation, and a reusable weekly practice. The case is fictional and the clinical specialty is deliberately unnamed.

The deliverable is `dist/index.html` and `dist/logo.jpg`. Copy the contents of `dist/` to any static host. For GitHub Pages, put these files at the repository root and enable Pages from the main branch, root folder. No build step or paid service is required.

Notes and progress use the visitor's local browser storage. No server, analytics, API key, or data submission is used. External tool and WhatsApp links open third-party services. The copyable prompts do not connect automatically to an AI service.
